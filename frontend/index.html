사용 방법

  1. PDF 파일을 추가합니다.
  2. 페이지를 클릭하고, Shift+클릭으로 연속된 여러 페이지를 선택합니다.
  3. 선택한 페이지를 왼쪽·오른쪽으로 90도씩 회전할 수 있습니다.
  4. 선택한 페이지를 한 칸씩 또는 맨 앞·맨 뒤로 이동할 수 있습니다.
  5. 필요 없는 페이지는 휴지통 버튼으로 삭제합니다.
  6. 한 페이지는 기존처럼 드래그해 순서를 바꿀 수 있습니다.
  7. 최종 PDF 만들기를 누르면 회전 상태와 현재 순서대로 합쳐집니다.
